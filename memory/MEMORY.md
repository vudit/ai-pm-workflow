# Memory Index

> This folder stores persistent memory across sessions. Files here are auto-managed by agents — they are created and updated as you work. You can read, edit, or delete any file here.
>
> When you first start using this workflow, this folder will be empty. It builds up over time as agents learn your preferences, record decisions, and observe patterns across projects.

---

## What gets added here automatically

| File type | Created when |
|---|---|
| `user_profile.md` | Agents learn your role, preferences, and working style |
| `feedback_*.md` | You correct an agent or confirm a non-obvious approach worked |
| `workflow_*.md` | You make architectural decisions about how this system operates |
| `pattern_*.md` | Agents observe recurring patterns across multiple projects |
